# Contributing to ToolTrust

Thanks for your interest. This project is in early development and is built mostly by an autonomous pipeline that the owner supervises, so the roadmap moves fast.

- Open an issue first for anything bigger than a small fix, so we can agree on the approach.
- Keep PRs to one topic, link the issue, and add or update tests.
- Run `npm run check` before pushing.
- By contributing you agree your work is licensed under Apache-2.0.

Human PRs are always reviewed by the owner; the autopilot never merges them.
